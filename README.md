# Python Chatbot 🤖

# About the Project

This is a beginner-friendly chatbot developed using Python. It interacts with users through the terminal and responds to different commands.

# Features

- Greeting and basic conversation
- Tells jokes
- Displays current date and time
- Motivational messages
- Compliments
- Simple calculator
- Quiz with questions and scoring
- Word counter
- Text reverse
- Riddle game
- Would You Rather game
- Chat history
- Restart conversation

# Technologies Used

- Python
- VS Code

# How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

python chatbot.py

# Purpose

The purpose of this project is to practise Python programming, conditional statements, loops, lists, dictionaries, functions and user input.
